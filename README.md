# Biofilm Multiphysics: Structural Mechanics of Biofilm on a Flexing Bellows

Structural-mechanics component of the dry-lab modelling for an iGEM project on biofilm in the ISS wastewater
tank. The project aims to engineer a *Bacillus subtilis* biofilm that competitively excludes undesirable
microorganisms, can be formed and thinned through externally controlled regulation, and avoids the excessive
accumulation that risks downstream clogging.

This repository contains a 2D finite-element (FEM) model of a biofilm attached to one convolution of a metal
bellows. It asks a mechanical question: how would a **hypothetical 50 % reduction in biofilm thickness** change
the loading the biofilm experiences when the bellows moves? The FEM does not simulate gene expression or any
specific regulatory mechanism. The thickness reduction is a controlled geometric scenario. The proposal's
candidate thinning mechanisms (SinI/SinR matrix control, matrix-degrading enzymes, γ-PGA-associated dispersal)
are not modelled here.

## Scientific objective

Under identical prescribed bellows movement, compare two hypothetical thickness scenarios, *unregulated*
(reference) and *regulated* (uniformly half-thickness, $h_r=0.5\,h_u$), in terms of:

- internal loading: von Mises stress, principal tensile stress and principal tensile strain;
- interfacial loading: normal and shear traction at the biofilm–metal interface.

These are **loading indicators**, not predictions of fracture or detachment.

## Quick start: reproduce everything

You need [conda](https://docs.conda.io/en/latest/miniconda.html) (Miniconda or Anaconda). Run every command from
the repository folder (`biofilm_multiphysics/`).

**1. Create the environment** (once; it takes a few minutes):

```bash
conda env create -f environment.yml
```

**2. Activate it** (every new terminal):

```bash
conda activate biofilm-fem
```

**3. Run the final notebook from scratch.** This executes every cell in a fresh kernel and saves the results
into the notebook (about 10 seconds):

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/FINAL_biofilm_mechanics.ipynb
```

The last table in the notebook should read **22/22 checks passed**. If any check fails, execution stops with
an error.

**4. Run the tests** (should report `8 passed`):

```bash
python -m pytest -q tests
```

**Optional: recreate the notebook itself.** The notebook is generated by a script. To rebuild it from that
script, then run it as in step 3:

```bash
python scripts/build_final_notebook.py
```

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/FINAL_biofilm_mechanics.ipynb
```

**Optional: explore interactively.** Open the notebook in JupyterLab and choose *Kernel → Restart Kernel and
Run All Cells*:

```bash
jupyter lab notebooks/FINAL_biofilm_mechanics.ipynb
```

**Verified reproduction.** On macOS (Apple Silicon), a fresh environment created from `environment.yml`
rebuilt and ran the notebook with output identical to the committed version, passed all 8 tests, and ran the
integration example in `docs/INTEGRATION.md`. Linux and Windows should also work with the same conda-forge
packages but were not tested. SfePy may print `install jax and jaxlib to use terms_jax.py!`; this is harmless
because `jax` is not used.

**Removing the environment:**

```bash
conda env remove -n biofilm-fem
```

## Main numerical findings

Baseline: bellows opening 60° → 60.5°, fold radius 20 μm, mean thickness 10 μm vs. 5 μm, $E=64$ Pa, $\nu=0.3$
(illustrative), production mesh of 14 970 triangles.

| Result | Value |
|---|---|
| 20 paired morphologies, mean reduction in max von Mises stress | **59.57 %** (20/20 pairs reduced) |
| … in max principal strain | **60.37 %** |
| … in area-weighted mean von Mises stress | **52.22 %** |
| Representative pair, max principal tensile stress reduction | **62.22 %** |
| Representative pair, interface tensile normal traction reduction (peak / mean) | 70.89 % / 76.86 % |
| Representative pair, interface shear traction reduction (peak / mean) | 49.39 % / 71.96 % |
| Effect of $E$ on percentage reductions | none (stress ∝ $E$, verified) |
| Opening angle 0.1°–1°, fold radius 15–40 μm, $\nu$ 0.2–0.45 | thinning reduces loading in every case; larger benefit on sharper folds |
| Mesh convergence (finest two meshes) | < 0.3 % change in bulk indicators; interface tractions within about 5 % |
| FEM-to-grid conservation of area and integrated stress | round-off (≤ $2.4\times10^{-16}$) |

Details, tables and provenance are in [VALIDATION_AND_LIMITATIONS.md](docs/VALIDATION_AND_LIMITATIONS.md).

## Scientific limitations

The model is a verified **screening tool**, not a validated prediction:

- $E$ and $\nu$ are illustrative values taken from the literature, not measured for our strain. Absolute
  stresses scale with $E$.
- Purely elastic, small-strain, plane-strain material; real biofilms are viscoelastic and heterogeneous.
- The bellows geometry is idealized and its motion is prescribed, not computed.
- Perfect adhesion; no self-contact, fracture, detachment or fluid loading.
- The 50 % thickness reduction is a hypothetical geometric scenario, not a measured effect of any genetic
  construct. Real interventions might also change stiffness, cohesion or adhesion, which are held fixed here.
- No experimental validation.
- Strain values changed in Stage 4, when a shear-strain convention error in the principal-strain calculation
  was fixed. Exploratory notebooks 02–04 still show the old strain values; stress results were unaffected
  ([§3.5](docs/VALIDATION_AND_LIMITATIONS.md#35-known-inconsistency-shear-strain-convention)).
