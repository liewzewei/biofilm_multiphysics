# Final notebook: provenance, reproducibility and audit notes

The deliverable is `notebooks/FINAL_biofilm_mechanics.ipynb`, generated by `scripts/build_final_notebook.py`
from the `src/` modules. The exploratory notebooks 01–04 were left unchanged.
`src/structural_fem.py` and `src/curved_structural_fem.py` were changed once, in Stage 4, to fix the
shear-strain convention (item 10 below).

## How to reproduce

The step-by-step commands are in the [README](../README.md#quick-start-reproduce-everything). In short:
create the environment from `environment.yml`, then execute the notebook with `nbconvert`, then run `pytest`.

Runtime is about 10 s. All 22 verification checks pass, and a failing check stops execution with an `assert`.
Every random profile comes from an explicitly seeded `np.random.default_rng(seed)`. A fresh environment built
from `environment.yml` reproduced every text output of the notebook identically (macOS, Apple Silicon).
`jax` is not required; SfePy's import warning about it is harmless.

## Audit findings (issues in existing files, left unchanged)

1. **Fold-radius study (04, cell 86) used a different thickness generator.** It passed $s/L_s\in[0,1]$ to
   `random_height_profile`, whose feature widths (15–60) are in input units. The result is a smooth monotonic
   ramp, not a rough morphology. The final notebook reproduces this study as is and adds a corrected run on
   $s$ in μm. At $R_0=20$ μm the corrected run reproduces the Section 10 baseline exactly.
   Both versions show that thinning helps more on sharper folds, but the corrected reductions span a wider
   range (66.7 % → 52.9 % for max von Mises over R0 = 15–40 μm, against 65.2 % → 55.9 % originally).
2. **`outputs/data/biofilm_sample_001.npz` cannot be regenerated.** It records `seed=42`, but the profile was
   produced by an unseeded call (`random_height_profile(x)` in 01, cell 3) and does not match seed 42.
   Notebook 01's outputs (mean height 40 μm) also predate the current default `mean_height=80`.
3. **Notebook 01 depends on stale kernel state.** Cells 21–22 use `MEAN_HEIGHT`, `ROUGHNESS` and `MIN_HEIGHT`,
   which notebook 01 never defines, so a fresh run raises `NameError`. Execution counts show out-of-order
   execution and deleted cells. Its mesh and area checks (cells 4–8) use a hand-built mesh, not `build_layer_mesh`.
4. **Some verification cells test local copies, not the module code.** The principal-stress tests (04, cell 93)
   and traction-decomposition tests (04, cell 111) check functions defined inside the notebook, not
   `solve_curved_biofilm` or `calculate_interface_traction`.
5. **The interface normal depends on a mesh convention.** `calculate_interface_traction` always uses the edge's
   left-hand normal. That normal points into the biofilm only for meshes built with `normal_side="left"`, which
   every current run uses. The final notebook verifies the orientation explicitly.
6. **Stress metrics differ between the flat and curved solvers.** The flat solver reports an interior
   (corner-excluded) peak, while the curved solver reports only the global peak. The two are not directly
   comparable.
7. **Notebook 02's force-balance check is approximate.** It integrates element stresses along the base
   (0.506 % error). It does not compute reactions from $\mathbf R=\mathbf K\mathbf U-\mathbf F$, as its
   markdown states.
8. **Hard-coded constant in notebook 03.** `F_REF = 5.252825e-6` N/m is copied from notebook 02's output.
9. **Stray artifact.** `notebooks/biofilm_domain.vtk` (4 MB) was written by `problem.solve()` with default
   saving in notebook 02, cell 15.
10. **Shear-strain convention (found in Stage 3, fixed in Stage 4).** SfePy's `ev_cauchy_strain` returns $\gamma_{xy}=2\varepsilon_{xy}$, and both solvers used it as $\varepsilon_{xy}$, which overestimated principal strains. Both solvers now halve it, and `tests/test_strain_convention.py` covers the fix. Stress outputs were unaffected. Notebooks 02–04 still show the pre-fix strain values. See `VALIDATION_AND_LIMITATIONS.md` §3.5.
11. **Observation, not verified.** The mean-stress reduction drifts with opening-angle change
    (57.1 % → 52.6 % for Δθ = 0.1° → 1°) while the max-stress reduction stays at about 60.5 %. This is
    consistent with linearization error from finite flank rotation, so Δθ should stay small.
